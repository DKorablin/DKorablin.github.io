# Deployed private releases
[![Auto build](https://github.com/DKorablin/DKorablin.github.io/actions/workflows/pages/pages-build-deployment/badge.svg)](https://github.com/DKorablin/DKorablin.github.io/actions)

Download builds of my private repository apps that are distributed directly from here rather than through an app store.

Pick a project in the sidebar to see what it does and its releases: each version is listed with its release date and files (with sizes), newest first. Older versions are collapsed under the latest one. Only recent releases are kept, and the oldest are removed automatically.
